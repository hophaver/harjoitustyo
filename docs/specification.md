# Specification


Aa command-line Connect Four game with a bot option implemented.

Project is done in Python and documented in English. (I can peer review projects implemented in Python, C++, and JavaScript / TypeScript.)


## Technical Requirements


## Functional Requirements

- The game is launched and played from the command line
- Board representation on a 6x7 grid
- Ability to select game modes (pvp or ai)
- Move validation so pieces aren't placed in columns already full
- Win detection checking the 4 valid directions from the last played piece
- Draw detection when the board is full
